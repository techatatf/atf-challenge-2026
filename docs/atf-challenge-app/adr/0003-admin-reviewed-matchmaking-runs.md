# Use Admin-Reviewed Matchmaking Runs

Status: accepted

Team formation will be system-generated and admin-approved through Matchmaking Runs instead of user-created teams. Admins can generate multiple Draft Matchmaking Runs, compare quality and coverage, approve one, and then publish Teams to Participants. This gives ATF operational control as the challenge scales from about 90 Teams to a target of about 2,500 Teams.

## Consequences

The app needs Participant Profiles, ranked Topic Preferences, Team Size Policy, Draft Matchmaking Run review, quality metrics, and a publish action. The Team Size Policy used for an Approved Matchmaking Run must be frozen for auditability.
